# منهجية تجهيز دورني للتثبيت وإشعارات الهاتف

> هذا سجل مرحلة تجهيز PWA الأولى. تنفيذ Web Push اللاحق وحالة نشره واختباراته موثقة في [WEB_PUSH.md](./WEB_PUSH.md).

## حدود هذه النسخة

هذه مرحلة تثبيت واستقرار التطبيق الحالي. لم يتم تفعيل إرسال Web Push أو تغيير قاعدة البيانات أو إعدادات الحسابات. كل العمل يخص Dorni فقط؛ Equal ID خارج النطاق.

## المنهجية

1. مراجعة المسار الكامل: حساب فردي/شركة، سيارة، بطاقة، مسح، بلاغ، رد، تحديث الحالة.
2. إصلاح الأعطال التي تمنع إتمام العملية أو تعطي انطباع نجاح غير مؤكد.
3. تجهيز تثبيت PWA وواجهة الموبايل والأوفلاين والتحديثات.
4. فحوص النوع والبناء والاختبارات، ثم مراجعة المتصفح بالفاتح والداكن.
5. إطلاق Push بعد اجتياز بوابات الاختبار أدناه على أجهزة حقيقية.

## ما تم إصلاحه وتجهيزه

- Manifest عربي، هوية ثابتة، بدء من الحساب، نطاق الموقع ووضع مستقل.
- أيقونات PNG عادية وmaskable وApple touch مشتقة من شعار دورني الحالي.
- صفحة /install، زر تثبيت عندما يدعمه المتصفح، وتعليمات Safari وChrome.
- Service Worker يخزن فقط صفحة الأوفلاين العامة؛ لا يخزن الحسابات أو API أو روابط متابعة البلاغ.
- تنبيه اتصال منقطع، وتحديث النسخة باختيار المستخدم كي لا يفقد نموذجاً يكتبه.
- استرداد من فشل التحميل والحفظ والنسخ والتنزيل؛ مهلة للطلبات؛ لا إعادة تلقائية لعمليات الكتابة.
- تحرير حالة busy في finally، ومنع تكرار إرسال البلاغ وهو قيد التنفيذ.
- استمرار المسح إذا المتصفح منع localStorage.
- تحديث بوابة الشركة كل 15 ثانية وهي ظاهرة، وتحديث المالك كل 5 ثوانٍ.
- توضيح حالة البلاغ المنتهي ومنع الرد على البلاغ المحلول أو المنتهي.
- فتح تبويب التنبيهات عند /app?tab=alerts.
- شروط كلمة المرور متوافقة مع تحقق الخادم، وإرجاع استعادة كلمة المرور لبوابة نوع الحساب.
- استجابات API لا تُخزَّن في كاش مشترك.

## ما وجدناه بخصوص Push

الموجود في lib/server/notifications.ts يرفض WEB_PUSH بحالة PUSH_SUBSCRIPTION_MISSING؛ ليس مزوّداً عاملاً. ملف NOTIFICATION_SYSTEM.md القديم يصف التصميم المستهدف، ولا يثبت تنفيذ إعادة المحاولة أو جدولة العامل.

تم تجهيز استقبال push والنقر عليه في Service Worker، لكن لا توجد واجهة اشتراك أو مفتاح VAPID أو إرسال فعلي في هذه المرحلة. لا نطلب إذن الإشعارات قبل تجهيز الإرسال، ولا نعرض زر نجاح وهمياً.

## مرحلة Push التالية

| العمل | معيار القبول |
| --- | --- |
| اشتراك الجهاز | زر بعد تسجيل الدخول؛ إذن من ضغطة المستخدم؛ حفظ subscription مرتبط بالمستخدم والجهاز |
| حماية الاشتراكات | RLS ملكية المستخدم؛ تسجيل الخروج يفصل الجهاز؛ حساب آخر لا يرث الاشتراك |
| مفاتيح VAPID | المفتاح الخاص في أسرار السيرفر فقط؛ العام متاح للاشتراك |
| إرسال البلاغ | outbox محفوظ مع البلاغ، إرسال لكل أجهزة صاحبه، دون كشف هوية الماسح |
| عامل الإرسال | جدولة موثوقة، مهلة واستعادة SENDING المتعطل، إعادة محاولة محدودة مع backoff |
| نهاية الاشتراك | تعطيل endpoint عند 404/410؛ إعادة المحاولة عند 429/5xx؛ منع الإرسال المكرر |
| الهاتف | النقر يفتح التنبيهات؛ إشعار والجهاز مقفول؛ رفض الإذن وإلغاؤه وتبديل الحساب |
| الاستضافة | معالجة نوم Render Free قبل اعتماد زمن وصول للإنتاج |
| المراقبة | قياس queued/sent/failed وعمر الرسالة دون تسجيل مفاتيح الاشتراك |

## اختبار القبول على أجهزة فعلية

- أندرويد Chrome وآيفون iOS 16.4+ من الشاشة الرئيسية.
- صاحب سيارة وشركة بحسابين اختباريين منفصلين؛ توليد بطاقة وتفعيلها.
- إعادة تحميل وإغلاق وفتح التطبيق، مع بقاء البيانات.
- إرسال بلاغ من جهاز آخر، ظهوره دون ريفريش، ورد المالك وتحول الصح من أحمر لأخضر.
- انقطاع الاتصال في التحميل والحفظ؛ عدم الإبلاغ عن نجاح غير مؤكد أو تكرار كتابة تلقائية.
- فاتح/داكن، عرض 360px، لوحة مفاتيح، safe area، عدم حجب الأزرار.
- بعد تفعيل Push: وصول إشعار والتطبيق مسكّر، والنقر عليه يفتح حساب المالك الصحيح.

المراجعة بالكود واختبارات العامل لا تغني عن اختبار المسار بحسابين وأجهزة فعلية. لا تُعتبر إشعارات الهاتف جاهزة للإطلاق قبل نجاح هذا الاختبار.

- نجح `npm run lint` و`npm run typecheck` و`npm run build`.
- نجح `npm test`: 23 اختباراً، منها 4 اختبارات تنفيذية لعامل الخدمة.
- تمت مراجعة صفحة التثبيت والدخول وإنشاء الشركة بصرياً على عرض 390px بالفاتح والداكن.
- تم اختبار عرض فشل تحميل صفحة المسح وإتاحة إعادة المحاولة دون إرسال بلاغ.
- بيئة التطوير تفتقد إعداد Supabase للخادم، لذلك لم يُتحقق محلياً من دورة الحساب والبلاغ والرد بين حسابين. لا تُعد اختبارات المصدر بديلاً عن اختبار التكامل.
- هذه النتائج تخص النسخة المحلية؛ لا تثبت نشرها على Render ولا وصول Push على هاتف فعلي.
